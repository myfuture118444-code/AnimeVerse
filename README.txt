ANIMEVERSE V2
==============

This version adds:
- Live anime search and trending data using Jikan API (https://jikan.moe/)
- Real poster images returned by the API
- Genre filtering
- Anime detail popup
- Local watchlist saved in the browser
- Dark/light theme
- Responsive mobile layout
- No episode hosting or unauthorized streaming

Run locally:
Open index.html in a browser. Internet access is needed for live anime data.

GitHub Pages:
1. Create a public GitHub repository named AnimeVerse.
2. Upload index.html, style.css and script.js.
3. Settings -> Pages -> Deploy from a branch -> main -> /root -> Save.
4. Open the Pages URL GitHub gives you.

Note:
Jikan is an unofficial MyAnimeList API. Its availability, limits, or response format can change. For a serious production site, consider a stable data provider and check the applicable terms for any data/images you use.
